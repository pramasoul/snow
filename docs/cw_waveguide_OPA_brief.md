# CW PPLN Waveguide OPA — Physics Brief for CC

## Purpose

Build a notebook that simulates a **CW-pumped χ⁽²⁾ optical parametric amplifier
in a PPLN waveguide**, using SNOW's waveguide propagation infrastructure (the
mode this time, not the bulk-crystal bypass). This models the emerging class of
integrated low-noise amplifiers in thin-film lithium niobate (TFLN).

The physics is the same parametric interaction as the bulk OPA notebook, but the
operating regime is fundamentally different: CW (no pulse dynamics, no GVM), low
power (milliwatts to watts, not µJ pulses), long interaction in a tightly
confining waveguide, and the figure of merit is noise figure rather than pulse
energy.

---

## Use Case

**Low-noise optical amplifier for telecom signals near 1550 nm.**

The competing technology is the erbium-doped fiber amplifier (EDFA), which has a
quantum-limited noise figure of 3 dB (phase-insensitive amplification). A
phase-insensitive χ⁽²⁾ OPA also has a 3 dB quantum limit, but a
phase-sensitive OPA (where signal and idler are both injected with a defined
phase relationship) can in principle achieve 0 dB noise figure — noiseless
amplification of one field quadrature.

The practical context: TFLN waveguides with PPLN poling are now commercially
available with propagation losses below 0.1 dB/cm and efficient quasi-phase
matching. This makes CW waveguide OPA a realistic prospect.

---

## Wavelength Geometry

### Phase-Insensitive OPA (simpler, do this first)

| Wave   | Wavelength | Notes                                    |
|--------|------------|------------------------------------------|
| Pump   | 775 nm     | SHG of a 1550 nm laser (standard approach)|
| Signal | 1550 nm    | Telecom C-band input to be amplified     |
| Idler  | 1550 nm    | Degenerate case: signal = idler          |

Wait — this is degenerate, which means it's automatically phase-sensitive.

For a clean phase-insensitive demonstration, use a **non-degenerate** geometry:

| Wave   | Wavelength | Notes                                    |
|--------|------------|------------------------------------------|
| Pump   | 775 nm     | Derived from SHG of 1550 nm              |
| Signal | 1540 nm    | Slightly detuned from degeneracy         |
| Idler  | 1560.3 nm  | Set by energy conservation               |

Check: 1/0.775 = 1.29032;  1/1.540 = 0.64935;  1/1.5603 = 0.64090;
0.64935 + 0.64090 = 1.29025 ≈ 1.29032  ✓

This is phase-insensitive because signal and idler are at different frequencies
and only the signal is injected. The idler is generated by the process.

### Phase-Sensitive OPA (advanced, later cells)

Same wavelengths, but now **both** signal and idler are injected at the input
with a controlled relative phase. When the relative phase is optimal, the gain
is twice that of the phase-insensitive case (in dB), and the noise figure
approaches 0 dB. When the phase is anti-optimal, the signal is deamplified
(squeezed). This phase-dependent gain is the key physics to demonstrate.

## Waveguide Parameters

### Geometry

Thin-film lithium niobate ridge waveguide, x-cut (or z-cut — check what SNOW
supports), with dimensions roughly:

- **Core width:** 1.5–2.0 µm
- **Film thickness:** ~600–700 nm (standard TFLN)
- **Etch depth:** ~300–350 nm (partial etch, rib waveguide)
- **Cladding:** SiO₂ below, air or SiO₂ above

These dimensions give single-mode operation at 1550 nm and support a guided mode
at 775 nm. The effective mode areas will be:

- A_eff(775 nm) ≈ 1–2 µm²
- A_eff(1550 nm) ≈ 3–5 µm²

The mode overlap integral between pump and signal modes, combined with d₃₃,
determines the effective coupling — and this is exactly where SNOW's waveguide
mode should do the heavy lifting. The overlap integral replaces the simple
d_eff/n·c coupling of the bulk case.

**If SNOW doesn't have a TFLN waveguide geometry built in**, a simpler starting
point: use a reverse-proton-exchanged (RPE) waveguide in bulk LiNbO₃, which has
larger mode areas (~30–50 µm²) and is an older but well-characterized technology.
The physics is identical, just weaker coupling per unit length, requiring longer
crystals or higher pump power. Use whatever geometry SNOW already supports rather
than building a new one from scratch.

### Poling period

For 775 nm → 1540 nm + 1560 nm QPM in TFLN at room temperature, Λ will depend
on the waveguide dispersion (not just bulk Sellmeier). If SNOW computes the
effective indices from the waveguide mode solver, let it determine the correct Λ.
Expect something in the range of 3–5 µm for TFLN (much shorter than the ~30 µm
for the bulk mid-IR OPA because the wavelengths are shorter and the waveguide
dispersion modifies the phase matching).

If SNOW doesn't have a waveguide mode solver and we need to fall back on
effective indices from the literature, typical values for a 700 nm TFLN
waveguide:

- n_eff(775 nm) ≈ 2.14
- n_eff(1540 nm) ≈ 2.07
- n_eff(1560 nm) ≈ 2.07

These are rough — the exact values depend sensitively on geometry.

### Crystal length

**10–50 mm.** TFLN waveguides up to 50 mm are fabricated. Start with 20 mm as
baseline and sweep length as a parameter.

### Propagation loss

This matters enormously for CW operation — unlike a pulsed OPA where the pulse
exits before loss accumulates, CW fields experience loss over the full crystal
length. Include propagation loss as a parameter:

- **State-of-the-art TFLN:** 0.03–0.1 dB/cm at 1550 nm
- **Typical research devices:** 0.1–0.5 dB/cm
- **At 775 nm:** Usually higher, ~0.2–1.0 dB/cm

Loss competes with parametric gain. There's a threshold pump power below which
loss wins and the device has net loss. This threshold behavior is one of the key
things to demonstrate.

## CW "Pulse" Parameters

Since SNOW is fundamentally a time-domain pulse propagation code, we need to
represent CW operation within its framework. Two approaches:

### Option A: Very long pulse (preferred if feasible)

Use a flat-top pulse much longer than any timescale in the problem (no GVM
walk-off in CW, so the only timescale is the simulation window). Something like
a 1 ns flat-top pulse. The center of the pulse will behave as CW. Extract
results from the center, ignoring edge effects.

### Option B: Steady-state extraction

If SNOW has a CW or steady-state mode, use that. The NEE in CW reduces to
an ODE in z (no time derivatives), which is much simpler and faster.

### Power levels

| Wave       | Power         | Notes                                 |
|------------|---------------|---------------------------------------|
| Pump       | 50–500 mW     | Achievable from PPLN-doubled 1550 nm  |
| Signal     | 0.1–1 mW      | Typical telecom signal level (-10 to 0 dBm) |
| Idler (PI) | 0 (vacuum)    | Generated by the process              |
| Idler (PS) | = Signal      | Injected for phase-sensitive operation |

For the waveguide mode areas above, 100 mW in a 2 µm² mode gives
~5 GW/m² = 0.5 MW/cm² — modest by pulsed standards but sufficient for
meaningful parametric gain in a cm-scale device.

### Cell 2: Phase-Insensitive OPA — Gain vs. Length

Propagate CW pump (100 mW) + CW signal (1 mW) through the PPLN waveguide.
No idler input.

**Plot A:** Signal power (dBm) and idler power (dBm) vs. propagation distance z
along the waveguide. In the undepleted-pump (small-signal) regime, signal gain
in dB should grow linearly with z (for large enough gL; quadratically for very
short z). The idler should track the signal.

**Plot B:** Overlay the analytical small-signal prediction G = cosh²(gL) on the
simulation data. This is the same validation we did for the bulk OPA, but now g
is computed from the waveguide coupling coefficient (including mode overlap).

**Expected behavior:**
- At 100 mW pump in a TFLN waveguide, expect g on the order of 1–10 /m,
  so over 20 mm, gL ≈ 0.02–0.2. That's very low gain — maybe 0.1–1 dB.
  This is physically correct for single-pass CW operation at modest power.
- To get useful gain (~10–20 dB), you need either more pump power (watts)
  or a longer waveguide (50 mm+), or both.

**This is the fundamental scaling challenge of CW OPA.**

### Cell 3: Gain vs. Pump Power

Fix waveguide length at 20 mm (or 50 mm). Sweep pump power from 10 mW to 2 W.

**Plot:** Signal gain (dB) vs. pump power (mW). Should be linear in √P at low
gain (quadratic regime), transitioning to linear in √P in dB at higher gain
(exponential regime). If pump power reaches the point where the signal
approaches the pump level, back-conversion appears.

**Key question to answer:** How much pump power is needed for 20 dB gain in
this waveguide? This number — the "useful gain threshold" — determines
whether the device is practical. For a well-confined TFLN waveguide with
good mode overlap, the answer from the literature is typically 100–500 mW
for ~10–20 dB gain in 2–4 cm. If the simulation gives wildly different
numbers, revisit the coupling coefficient (same X0 question as the bulk
notebook).

### Cell 4: Effect of Propagation Loss

Take the best-case pump power from Cell 3 (say 200 mW, 50 mm waveguide) and
sweep the propagation loss parameter:

- 0 dB/cm (ideal)
- 0.05 dB/cm (state-of-the-art TFLN)
- 0.2 dB/cm (typical)
- 0.5 dB/cm (lossy)
- 1.0 dB/cm (poor)

**Plot:** Net signal gain (dB) vs. propagation loss (dB/cm). There should be a
crossover point where loss exceeds parametric gain and the device becomes a
net attenuator.

**This is the plot that shows why TFLN fabrication quality matters** — the
difference between 0.05 and 0.5 dB/cm can be the difference between a useful
amplifier and a paperweight.

### Cell 5: Gain Bandwidth

Sweep signal wavelength across the C-band (1530–1565 nm) at fixed pump power
and crystal length.

**Plot:** Gain (dB) vs. signal wavelength. The gain bandwidth is set by the
phase-matching bandwidth, which depends on waveguide dispersion and crystal
length. Longer crystals give higher peak gain but narrower bandwidth — this is
the gain-bandwidth tradeoff fundamental to parametric amplifiers.

**Overlay curves for 10 mm, 20 mm, and 50 mm crystals** to show the tradeoff
explicitly.

**Target from literature:** TFLN PPLN waveguide OPAs can achieve gain bandwidths
of ~10–100 nm depending on length and dispersion engineering. If the simulation
shows a bandwidth of 0.1 nm or 1000 nm, something is wrong.

### Cell 6: Phase-Sensitive Operation

This is the payoff cell — the physics that makes parametric amplifiers special.

Inject **both** signal and idler at the input with equal amplitudes and sweep
the relative phase φ from 0 to 2π.

**Plot A:** Signal gain (dB) vs. relative phase φ. Should oscillate between
a maximum of ~2G_PI (twice the phase-insensitive gain, in dB) and a minimum
that corresponds to deamplification (gain < 0 dB — the signal comes out
weaker than it went in).

**Plot B:** Signal + idler total output power vs. phase. The total parametric
process is conservative (energy comes from the pump), so when one quadrature
is amplified, the conjugate quadrature is deamplified. The phase-sensitive
gain curve directly demonstrates squeezing.

**Expected behavior:** If the phase-insensitive gain is G_PI dB, then:
- Maximum phase-sensitive gain ≈ 2·G_PI dB (at optimal phase)
- Minimum phase-sensitive gain ≈ −2·G_PI dB (deamplification)
  (This is approximate; exact expressions involve sinh and cosh.)

This 6 dB range (for G_PI = 3 dB) or larger is the direct manifestation of
the 0 dB noise figure property — the amplifier distinguishes between
quadratures, amplifying one noiselessly at the expense of the other.

## Notes for CC

1. **SNOW's waveguide mode:** This notebook should use SNOW's waveguide
   propagation infrastructure rather than the bulk NEE. The coupling
   coefficient should come from the mode overlap integral computed by SNOW,
   not from the manually calibrated X0. If the waveguide mode's X0 is the
   original 1.1e-12 value that was "designed for waveguide modes," this is
   where it should be correct by construction. Verify by comparing the
   simulated small-signal gain against the analytical cosh²(gL) formula
   with g derived from the mode overlap.

2. **CW representation:** If using a long flat-top pulse to approximate CW,
   make sure the pulse is long enough that the center 80% is free of edge
   artifacts. Monitor for numerical instabilities that might arise from the
   sharp edges of the flat-top (consider a super-Gaussian with gentle
   roll-off). If the time-domain grid becomes impractically large for ns
   pulses, consider whether SNOW can be driven in a z-only ODE mode by
   collapsing the time dimension to a single point.

3. **Phase-sensitive operation (Cell 6):** The phase between signal and idler
   must be set relative to the pump phase. If A_pump = |A_p|, A_signal =
   |A_s|·exp(iφ_s), A_idler = |A_i|·exp(iφ_i), then the relevant phase is
   φ_pump − φ_signal − φ_idler (for DFG/OPA). Sweep this composite phase.
   Make sure the simulation preserves phase coherence — numerical phase
   noise will wash out the phase-sensitive effect.

4. **Grid requirements:** CW operation means narrow spectral features — the
   pump, signal, and idler are essentially delta functions in frequency (or
   very narrow CW lines). The spectral grid needs to resolve these without
   aliasing. A fine frequency grid (large time window) with a small number
   of temporal points might be more efficient than the other way around.
   Alternatively, three discrete frequency bins might suffice if SNOW can
   operate in that mode.

5. **Noise modeling (stretch goal):** The ultimate test of a CW OPA model is
   noise figure. This requires injecting vacuum fluctuations (half a photon
   per mode) at the signal and idler frequencies and measuring the
   signal-to-noise ratio degradation through the amplifier. This is
   quantum-optical territory and may be beyond what SNOW's classical field
   solver can handle directly, but even a classical noise figure estimate
   (ratio of output SNR to input SNR, where input noise is shot noise) would
   be illuminating. Flag this as optional.

6. **Connection to the X0 calibration issue:** If SNOW's waveguide mode gives
   a coupling coefficient that produces physically reasonable gain without
   empirical fudging, that tells us the X0 = 1.1e-12 was correct for the
   waveguide geometry all along, and the factor-of-20 mystery in the bulk
   notebook was purely a normalization mismatch from using a waveguide code
   for bulk propagation. This would be a satisfying resolution.
